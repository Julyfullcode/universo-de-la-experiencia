# Planetary surface textures

Author/provider: Solar System Scope / INOVE.
Original source and license declaration: https://www.solarsystemscope.com/textures/
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/

The source states that the maps use NASA elevation and imagery data, with enhanced saturation and fictional fill where source coverage is incomplete. Earth incorporates Blue Marble data. Texture pixels are unchanged. Runtime shading, spherical geometry, atmospheric shells and motion are project-authored.

Retrieved 2026-09-15 through GitHub's file API from the public mirror `Whitebee7/solarsystem`, `textures/`, because direct source download was unavailable from the build environment. The mirror attributes these files to Solar System Scope in its README and LICENSE-textures.md. All files are stored locally; production does not fetch textures from a third-party origin.
